# ask-matt

[中文](README_CN.md)

An explicitly invoked guide to choosing an engineering skill or workflow, with availability checks for optional skills.

## Usage

Install and enable this plugin in ZCode, then use its `ask-matt` skill. Slash-command spelling may be namespaced by the client.

Invoke `ask-matt` explicitly and describe your situation. This package contains the router and phase-boundary reference only. Other workflow skills are optional and must be installed separately; the adapted guide checks availability before routing and does not auto-install them.
