# ask-matt

[English](README.md)

手动调用的工程技能与工作流导航，推荐前检查相关技能是否已安装。

## 使用

在 ZCode 安装并启用本插件后使用 `ask-matt` 技能。客户端可能为斜杠命令添加插件命名空间，以实际显示为准。

手动调用 `ask-matt` 并描述当前问题。本插件仅包含导航和阶段边界参考；引用的其他工作流技能需另行安装。适配版会先检查技能是否可用，不会自动安装整套技能或修改项目配置。
