# ponytail

[中文](README_CN.md)

Simple coding decisions: reuse existing code, prefer native tools, and implement the smallest working solution.

## Usage

Install and enable this plugin in ZCode, then use its `ponytail` skill. Slash-command spelling may be namespaced by the client.

Invoke `ponytail`, `ponytail lite`, or `ponytail ultra`, or ask for a minimal coding solution. The default level is `full`. Say `stop ponytail` to exit. No scripts, external services, or other skills are required.
