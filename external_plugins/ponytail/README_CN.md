# ponytail

[English](README.md)

简化编码决策：复用现有代码，优先标准库和原生能力，实现最小可行改动。

## 使用

在 ZCode 安装并启用本插件后使用 `ponytail` 技能。客户端可能为斜杠命令添加插件命名空间，以实际显示为准。

调用 `ponytail`、`ponytail lite` 或 `ponytail ultra`，或要求最小化编码实现。默认强度为 `full`；用 `stop ponytail` 退出。无需脚本、外部服务或其他技能。
