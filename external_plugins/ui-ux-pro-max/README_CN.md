# ui-ux-pro-max

[English](README.md)

内置可检索设计数据库与 Python 工具的 UI/UX 设计指南。

## 使用

在 ZCode 安装并启用本插件后使用 `ui-ux-pro-max` 技能。客户端可能为斜杠命令添加插件命名空间，以实际显示为准。

调用 `ui-ux-pro-max`，或提出界面设计、配色、交互与体验审查需求。数据库检索需要 Python 3；没有 Python 时仍可阅读指南。从已安装技能目录定位脚本，执行 `python3 <技能目录>/scripts/search.py "SaaS dashboard" --design-system`。完整 CSV 数据与 Python 工具已包含，无需 API Key 或额外 Python 依赖。示例中的路径占位符需要替换为实际安装路径。
